# To-do-list Project (OAO)

Professional starter To-do-list built with Vite, React, Tailwind CSS and Framer Motion.
This is a provisional, ready-to-run starter you can use, customize, and deploy to Vercel.

## Setup (locally)
1. Extract the ZIP and open the folder in a terminal.
2. Run `npm install` to install dependencies.
3. Run `npm run dev` to start the dev server.
4. Build with `npm run build` and preview with `npm run preview`.

## Features included
- Add, edit, delete tasks
- Mark tasks complete / active
- Due date support (date input)
- LocalStorage persistence
- Filters (All / Active / Completed)
- Blue–Purple gradient professional theme
- Framer Motion animations
- Responsive & ready for deployment
